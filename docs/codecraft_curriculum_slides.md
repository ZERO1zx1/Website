## Slide 3

# HTML: вебийн утга ба бүтэц

- **4 долоо хоног · Анхан шат** гэсэн богино, ойлгомжтой гараа
- Browser, document, tag, element, nesting, hyperlink, semantic structure-г тайлбарлана
- Хүртээмжийг эхнээс нь төлөвлөх: `main`, `article`, `nav`, `label`, зөв гарчгийн шатлал
- Дадлага: personal page, link navigation, semantic article layout

## Slide 4

# CSS: дизайн систем ба responsive сэтгэлгээ

- **4 долоо хоног · Анхан шат**
- Selector, cascade, specificity, box model, spacing, typography, color-ийг цэгцтэй ойлгоно
- Flexbox, Grid, media query ашиглан дэлгэц бүрт тохирох layout бүтээнэ
- Дадлага: card component, hero section, mobile-first page

## Slide 5

# JavaScript: статик хуудсыг интерактив болгох

- **5 долоо хоног · Анхан шат**
- Variable, data type, operator, condition, loop, function гэсэн логик суурь
- DOM query, event listener, form validation, class toggle болон state update
- Дадлага: theme toggle, todo interaction, quiz response, DOM-driven UI

## Slide 6

# Python: асуудал задлах programming суурь

- **6 долоо хоног · Анхан шат**
- Interpreter, value, variable, data type, list, condition, loop, function гэсэн ойлголтууд
- Алдаа унших, input/output шалгах, жижиг script-ийг өөрөө турших дадал
- Дадлага: score evaluator, course list manager, simple automation script

## Slide 7

# Lesson бүр унших материал биш, хийх алхам

| Lesson block | Суралцагчийн ашиг |
|---|---|
| Concept | Нэр томьёо болон гол санааг Монгол хэлээр ойлгоно |
| Mental model | Техникийн ойлголтыг бодит зүйрлэлээр тогтооно |
| Code example | Ажиллах жижиг кодоос structure-г харна |
| Common mistake | Түгээмэл алдааг эрт танина |
| Practice + quiz | Ойлголтоо туршиж, өөрийгөө шалгана |

## Slide 8

# Code Lab: мэдлэгийг туршилтаар бататгана

- Course болон lesson-оос starter code-г сонгож нээх workspace
- HTML, CSS, JavaScript, Python-ийн суурь syntax-ийг тус тусад нь турших гадаргуу
- “Run / submit” үйлдлийг backend evaluation-д өргөтгөх бэлтгэлтэй
- Lesson → Practice → Completion гэсэн урсгалыг таслалгүй хадгална

## Slide 9

# Ахиц нь хэрэглэгчтэй хамт хадгалагдана

- Supabase Auth ашиглан email/password болон Google sign-in архитектур
- `profiles`, `lesson_progress`, `course_progress` гэсэн learner-owned data model
- Row Level Security: суралцагч зөвхөн өөрийн profile, lesson completion-оо харах ба өөрчлөх эрхтэй
- Dashboard дээр completed lesson, course percentage, next learning action-г нэгтгэн харуулна

## Slide 10

# Дараагийн хөгжлийн чиглэл

- Google OAuth provider credentials-ийг идэвхжүүлж live sign-in-ийг баталгаажуулах
- Code Lab-ийн run/submit evaluation болон бодит feedback нэмэх
- Course completion certificate, streak, teacher view, analytics өргөтгөл
- Шинэ modules: Git/GitHub, APIs, Flask projects, portfolio capstone
